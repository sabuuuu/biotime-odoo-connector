# Transaction Report

- **Method:** GET
- **Url:** /att/api/transactionReport/
- **Headers:**

  - **Authorization**: "JWT ey.........oQi98"
- **Query Parameters**

| Parameter | Description |
| --- | --- |

| end_date | Use this field to query,example: ?end_date=2022-07-05 |
